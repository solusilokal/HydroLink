# HydroLink 🚢

> **Mini Website Jasa Transportasi Kapal Cepat & Terpercaya**  
> Solusi transportasi laut premium yang menghubungkan antarpulau dengan aman, cepat, dan nyaman.

---

## 🌊 Fitur Utama

- **Hero Header Interaktif**: Tampilan landing mobile-first dengan profil resmi HydroLink, deskripsi armada, dan link sosial media (Instagram, TikTok, Google Maps).
- **Highlights Layanan**: Tepat Waktu, Armada Modern, dan Asuransi Penuh.
- **Katalog Armada**:
  - **Hydro Fast**: Kapal Cepat (120 Penumpang, 35 Knots).
  - **Hydro Ferry**: Kapal Feri Ro-Ro (500 Penumpang & 80 Kendaraan, 18 Knots).
  - **Hydro Cruiser VIP**: Kapal Pesiar Mini (50 Penumpang VIP, 25 Knots).
- **Galeri Foto & Lightbox**: Modal fullscreen dengan navigasi swipe/klik antar armada.
- **Daftar Rute & Tarif**: Informasi harga transparan untuk berbagai rute populer antarpulau.
- **Formulir Pemesanan Tiket Cepat**: Terintegrasi langsung ke WhatsApp Official HydroLink (+6289529605601).
- **Tanya Jawab (FAQ)**: Akordeon interaktif untuk info bagasi, refund/reschedule, fasilitas medis, dan muatan kargo.
- **Testimoni Penumpang & Lokasi Dermaga**: Review pelanggan terverifikasi dan tautan Google Maps Pelabuhan Rambang.
- **Modal Berbagi (Share Sheet)**: Dukungan Web Share API dan tombol share instan ke WhatsApp, Twitter/X, Facebook, atau Salin Link.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/solusilokal/HydroLink.git
   cd HydroLink
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka `http://localhost:3000` di browser Anda.

4. **Build untuk production**:
   ```bash
   npm run build
   ```

Atau cukup klik ganda file **`start-preview.bat`** di Windows untuk menjalankan secara otomatis.
